# Kev テトリス強化学習: 全体計画

最終更新: 2026-09-26

## 1. 目的

- ローカルの決定モデル Kev(Kev-4B)にテトリスを覚えさせ、強化学習で上達させる
- 上達していく様子を、X でライブ配信する

## 2. 仕組み(現状)

**Kev への問いかけ(インターフェース)**
- 状態: 盤面のテキスト、現在のミノ、次のミノ(1個だけ)、列の高さ、穴の数
- 質問: 置き場所の候補から1つを選ぶ Choice 質問。各候補には、置いた結果の「消えるライン・穴・最高の高さ・凸凹・最も深い井戸」を説明として付ける
- **Kev に見せるのは、現在と次のミノだけ**。それより先のミノや、先読みの結果は見せない(方針として決定)

**1世代の流れ**
1. **練習試合**: 少しランダムに手を選んで16ゲーム遊び、プレイの記録を集める(1ゲーム200手で打ち切り)
2. **学習**: 記録から予想より良かった手を選び、その手を選ぶように Kev の重みを調整する(`kev.train`、LoRA)
3. **実力テスト**: ランダムなしで5ゲーム遊ぶ(同じブロック順、500手で打ち切り)。平均得点をその世代の成績にする

**運用**
- 配信画面は http://127.0.0.1:8765/ 、学習の操作ページは `/control`(開始・一時停止・再開・停止)
- 学習は止めるまで世代を重ね続ける(`--generations 0`)
- 構成の詳細は [README](../README.md) と [Kev ローカルサーバー運用ガイド](kev-local-deployment.md) を参照
- 環境: RTX 5060 Ti(VRAM 16GB)、Windows 11、Kev-4B(bf16)

わかったこと:
- 生き残る力は大きく伸びた。第5・6世代では、テストの手数が上限の500手に達している
- 1ラインあたりの得点は、どの世代も 110〜118 点のままだった(1列消しだけなら100、すべて4段消しなら200)。**ほぼ1列消ししかしておらず、高得点を狙うプレイになっていない**
- 世代間の成績は上下に揺れる(第3世代、第7・8世代で後退)
- v2 の第9世代では、テトリスが1ゲームあたり1.6回に増えた(第6世代は0.2)。一方で、500手まで生き残ったゲームは0/5に落ちた。今の腕前は、生存と高得点が両立しなくなる水準には遠く、これは代償ではなく学習の不足だ。**両方を満たすことを目標にする**

## 4. 現在の段階: 報酬 v2(第9世代〜)

生き残る力は保ったまま、4段消しを狙わせるための見直し。ゼロからではなく、**第6世代から枝分かれ**させた(第7・8世代は v1 の系統として残す)。

| 項目 | v1 | v2 |
|---|---|---|
| 4列消し | +8 | **+16** |
| 高さの増加 | −0.05 | **なし**(4段消しの準備では必然的に高く積むため) |
| 割引率 | 0.9 | **0.97**(何手も先で報われる準備の手を評価しやすくする) |
| 打ち切った練習試合の末尾で評価から外す手数 | 20手 | 60手 |
| 指示文 | 低く平らに保つ | 1列を深い井戸として空け、I ミノで4段消しを狙う |
| 候補の説明 | — | 「最も深い井戸」を追加 |
| 学習データ | 直前2世代分も混ぜる | 同じく直前2世代分。ただし **v2 で選んだ手だけ** |
| テストの成績 | 平均得点 | 平均得点に加えて **1ラインあたり得点・テトリス回数** |

テストの上限は、これまでの世代と比べられるように 500 手のままにした。

**判断の基準**: 数世代(目安は3世代)見て、1ラインあたり得点とテトリス回数が伸びているかを確認する。同時に、生き残り(500手まで生存した数)が崩れていないかも見る。伸びていなければ、次の v3 に進む。

## 5. 次の段階: v3(学習方針の見直し)

**v3 の全体像(2026-09-26 決定、第12世代から実施中)**: 第11世代(v2)のテスト後に切り替え、第12世代を第6世代から学習している。v3 で十分に育てたあと、0.8B に蒸留する。

| 項目 | 内容 |
|---|---|
| 長期的な連携 | 直前10手のウィンドウ(1手ずつずらす)で手を評価する(5.1) |
| 途中での回転・移動 | 左右移動・回転・落下でたどり着ける場所をすべて候補にする(5.2) |
| 穴の報酬の細分化 | 塞がった穴 −1.0、オーバーハング −0.5、解消 +0.8(5.3) |
| 天井近くの減点 | 上から4段以内に積んだときだけ減点する(v2 で生き残りが落ちたため) |
| 練習試合を長く | 打ち切りを200手から400手にして、積みすぎて死ぬ場面も学べるようにする |
| 練習試合での穴の回避と探索 | 穴を作らない候補がある限り、そこから選ぶ(まれに例外)。85%の手は Kev の一番の手、15%だけ上位3候補から探索する(全候補からのくじ引きでは、ありえない盤面ばかりになったため) |
| 4段消しの練習問題 | 練習試合の4分の1を、井戸があり何段か準備済みの盤面から始める |
| 親の世代の選び方 | 直近数世代のうち、テストの成績が最も良い世代を親にする |
| 分岐元 | それまでで最もテストの成績が良い世代(現時点では第6世代) |

**0.8B への蒸留の条件(案)**: v3 の世代が「500手まで5ゲーム中4以上生き残る」「1ラインあたり140点以上」「テトリスが毎ゲーム数回」を満たしたら、その世代を先生にして蒸留する。


v2 の効果を見てから、次をまとめて入れる。v2 の検証が濁らないよう、それまでは入れない。

**5.1 学習データの選び方: 10手ウィンドウ**
4段消しには10手以上の連携が要る。1手ずつ選ぶ方式では、準備の手が評価されにくい。
- 各手で終わる「直前10手」をウィンドウとし、1手ずつずらす
- ウィンドウの評価 = ウィンドウ内で得た報酬 +(終わりの盤面の良さ − 始まりの盤面の良さ)。盤面の良さは、穴の少なさ、4段消しの準備ができた行数、井戸の深さで測る
- 各手の評価は、その手を含むウィンドウの評価の平均。4段消しを含むウィンドウには重みを足す
- 同じ手は1回だけ学習データに入れる。ウィンドウ内で新しく穴を開けた手は除く
- ウィンドウの評価は記録の足し引きだけなので、学習時間はほぼ増えない

**5.2 テトリス本体: 滑り込み・回転入れ**
- 今は「上で回転して真下に落とす」置き方だけを候補にしている
- 出現位置から左右移動・回転・1段落としでたどり着ける場所をすべて候補にする。オーバーハングの下への滑り込みも打てるようにする
- 候補は約34通りから40〜60通りに増える見込み(問いかけが長くなり、推論が少し遅くなる)

**5.3 穴の報酬**

| 項目 | v2 | v3 案 |
|---|---|---|
| 完全に塞がった穴が増える | −0.4 | −1.0 |
| オーバーハング(上にブロックがあり、横が開いた空白)が増える | −0.4(穴と同じ扱い) | −0.5 |
| 穴・オーバーハングが解消される(滑り込みで埋めた/上のラインが消えて穴でなくなった) | 0 | +0.8/マス |

解消の加点は、発生の減点より小さくしておく(「わざと穴を作ってから埋める」で点を稼げないようにするため)。候補の説明でも、塞がった穴とオーバーハングを分けて表示する。

**5.4 保留中の案(必要なら検討)**
- 練習試合で、新しく穴ができない候補がある限りその中から選ぶ(すべてで穴ができるときだけ例外を許す)
- 練習試合のくじ引きの温度を 1.0 から 0.5 程度に下げる(Kev サーバーはもともと確率を平たくして返しているため)
- 1世代で学習する手の数に上限を設ける。練習試合が毎回200手まで続くようになると、学習だけで約2時間かかる見積もりのため

### 5.5 v4(第14世代から実施中)

**2026-09-26**: v3 は新ルールで伸び悩んだ(第12世代 36.3 点/ミノ・151手 → 第13世代 30.2・86手)ため、v4 を前倒しした。前半(5.7 の報酬・盤面の評価・名手の記録・テスト10ゲーム)を第14世代から入れ、第12世代を親にしている。後半(下の 1・2)はこのあと入れる。

**第15世代からの調整**: 第14世代(v4 最初)は、テトリスが初めて出た(0.5回/ゲーム)一方、平均84手で負けた。テストの録画では、10ゲームとも「ほとんどの列を18〜20段まで積み、深い井戸を2〜3本残したまま、出現位置で重なって負ける」形だった。そこで次の3点を調整した。
- 一番深い井戸以外の井戸の深さに減点(盤面の良さに −0.3 × 余分な井戸の深さ)
- 積みすぎの減点を12段から始める(v3 は16段から)
- オーバーハングの減点を −0.5 から −0.8 にする。Kev への指示にも「井戸は1本」「盤面の半分くらいまで」を加えた

**第16世代から: 先読み探索を先生にする(v4 後半を前倒し)**: 第15世代も 28.8 点/ミノ・平均83手で改善せず、ルール3になってから5世代続けて頭打ちだった。報酬の調整だけでは足りないと判断した。練習試合の各局面で、現在と次のミノの置き場所の組み合わせを読む2手の先読み探索(盤面の良さは v4 の評価)を先生にする。Kev が打った局面に先生の手をラベルとして付けて学習する(エキスパート・イテレーション / DAgger)。先生だけでプレイさせると、300手を生き残り、1ミノあたり55〜57点を取れる。学習データは、先生と Kev の手が食い違った局面を中心に、1世代あたり最大600手にする。

#### 当初の案

**基本方針**: 長期の戦略を立てられるようにする。見せるのは現在と次のミノだけ、という条件は変えない。

1. **Kev 自身に盤面の良さを答えさせる**: 段階評価の質問を追加して学習させ、手の評価の基準(今は盤面の特徴の単純な式)を置き換える
2. **練習試合で2手の先読み探索**: 見えている現在と次のミノだけで2手の組み合わせを比べ、探索で見つけた手を覚えさせる(AlphaZero 型)
3. **名手の記録を繰り返し学ぶ**: 1ミノあたり得点が高かったゲームを世代をまたいで保存し、学習データに混ぜる
4. **連続テトリスへの加点**: 報酬だけに入れ、ゲームの得点ルールは変えない
5. **テストの精度を上げる**: 10ゲームにして、同じブロック順で前の世代と比べる
6. **ホールド機能(要相談)**: 戦略の幅は広がるが、ルールが変わり過去の世代と比べにくくなる

### 5.7 過去の事例の調査と v4 の報酬(2026-09-26)

| 事例 | 効いたもの |
|---|---|
| Dellacherie の評価関数 | 穴の数、置いた高さ、行遷移、列遷移、井戸の深さの合計、浸食セル(消したラインで埋めた自分のマス)の6つの特徴量 |
| BCTS(Thiery & Scherrer) | 上の6つに「穴の深さ」「穴のある行数」を追加し、CE 法で重みを学習 |
| CBMPI(Gabillon, Ghavamzadeh, Scherrer, NeurIPS 2013) | 数手先まで試しに打つ(ロールアウト)方策改善。少ないサンプルで CE 法と同等。学習に使う盤面は、いろいろな高さから集めた方が良い |
| DQN の実装例 | 報酬 = 1 + 10 × (消したライン数)²。まとめ消しを強く優遇し、ゲームオーバーの罰は小さめ |
| Cold Clear(対戦用 AI) | 安全な間は1列・2列消しを減点、4列消しと T-スピンを加点。連続テトリス、井戸の深さ、覆われたマス、高さの帯も評価 |
| 報酬の整形(Ng ほか 1999) | 盤面の良さの差分だけを足すポテンシャル型なら、最適な方策を変えずに学習を速められる |

**v4 の報酬と評価(案)**

- 状況で変わる消し方の評価: 安全な高さ(最高10段以下)では 1列 +0.2・2列 +0.8、危険な高さでは生き残り優先で v3 と同じ。4列消しは常に +16
- 連続テトリス(Back-to-Back)に +8、T-スピン(T ミノを回転で入れ、四隅のうち3つが埋まっている形)に加点。ゲームの得点ルールは変えない
- 盤面の良さを Dellacherie/BCTS の特徴量(行遷移、列遷移、穴の深さ、穴のある行数、井戸の合計)で測り、ポテンシャル型の整形と手の評価の基準に使う
- 練習問題を、中くらいから高い積み上がりや、穴のある盤面にも広げる(CBMPI の知見)
- 5.5 の案(Kev 自身に盤面の良さを答えさせる、2手の先読み探索、名手の記録、テスト10ゲーム)と組み合わせる

参考: [The Game of Tetris in Machine Learning(Algorta & Şimşek)](https://arxiv.org/abs/1905.01652)、[CBMPI(NeurIPS 2013)](https://papers.nips.cc/paper/5190-approximate-dynamic-programming-finally-performs-well-in-the-game-of-tetris.pdf)、[nuno-faria/tetris-ai](https://github.com/nuno-faria/tetris-ai)、[Cold Clear](https://github.com/MinusKelvin/cold-clear)

**基本方針(2026-09-26)**: テトリス狙いは強く持つが、穴やオーバーハングができたらすぐに直す。第17世代から、穴とオーバーハングが残っている間は1マスにつき毎手 −0.15 のコストを課し(早く直すほど得)、Kev への指示にも「できたらすぐ直し、そのあと4段消しの準備に戻る」を加えた。

### 5.8a 0.8B への切り替え(2026-09-26 決定)

第16世代(先生つき学習の最初)で 47.4 点/ミノ・平均365手・テトリス2回/ゲームまで伸びた。このやり方で頭打ちになったら(1ミノあたり得点と平均手数が2〜3世代続けて伸びない)、Kev-0.8B に切り替える。
1. 4B の最良世代に多めのゲームを打たせ、出会った全局面に先生の手をラベル付けする(これまでの先生つき世代のデータも加える)
2. 元の Kev-0.8B から、このデータで0.8B の最初の世代を作る(蒸留)
3. 0.8B で先生つき学習を続ける(CUDA グラフも有効化)。4B の最良世代に届かなければ 4B に戻す
4. v5(下記)は 0.8B に移ってから入れる

### 5.8 v5 の案(先生つき学習が頭打ちになったら)

頭打ちの目安: 1ミノあたり得点と平均手数が、2〜3世代続けて伸びない。

1. **局面に応じた戦い方の切り替え**
   - 先生の評価を高さの帯で変える(Cold Clear 型): 低い(3分の1以下)は井戸掘りと4段消しの準備を重視し、1列・2列消しはほぼ評価しない。穴があるときは、穴の上の段を消して解消することを最優先。半分を超えたら生き残り重視で、どの消し方も評価し、高さを強く減点し、平らにする
   - Kev への問いかけに、局面の一行(「低い: 4段消しの準備」「穴あり: 穴の解消を優先」「高い: 生き残り優先」)を加える
2. **複数手の連携**
   - 先読みを3手目まで広げる。3手目のミノは見えないので、7種類それぞれの最善手の平均で評価する(見えない情報は使わない)
   - 先生が選んだ一連の手を、つながりとして学習させる

### 5.6 ゲームのルールの見直し(第12世代から)

- ミノは最上段の中央に出現し、そこで重なったらゲームオーバー(以前は、置き場所が1つでもあれば続行し、どの列にも上から降りてこられた)
- 回転は標準の SRS(回転の中心と壁蹴りの表)。着地後の回転や T-スピンも正しく扱う
- 置き場所は、出現位置から左右移動・回転・1段落下でたどり着ける場所すべて
- 過去の世代の録画は、記録したときのルール(ルール1)で再生する

## 6. 高速化

詳細は [高速化構想](speedup-plan.md) にまとめた。要点は次のとおり。
- 練習試合とテストの複数ゲームを同時に進め、Kev サーバーのまとめ処理を活かす(Windows のままでも可能)
- Docker(WSL2 の Linux コンテナ)で `flash-linear-attention` と `causal-conv1d` を使う
- 本命は **Kev-0.8B + CUDA グラフ**。4B の最良世代から蒸留してから、強化学習を続ける
- 0.8B が駄目なら、**Kev-4B + 高速化ライブラリ(CUDA グラフなし)** に戻す
