# Kev テトリス強化学習: 全体計画

最終更新: 2026-09-27

## 1. 目的

- ローカルの決定モデル Kev(Kev-4B)にテトリスを覚えさせ、強化学習で上達させる
- 上達していく様子を、X でライブ配信する

## 2. 仕組み(現状)

**Kev への問いかけ(インターフェース)**
- 状態: 盤面のテキスト、現在のミノ、次のミノ(1個だけ)、列の高さ、穴の数
- 質問: 置き場所の候補から1つを選ぶ Choice 質問。各候補には、置いた結果の「消えるライン・穴・最高の高さ・凸凹・最も深い井戸」を説明として付ける
- **Kev に見せるのは、現在と次のミノだけ**。それより先のミノや、先読みの結果は見せない(方針として決定)

**1世代の流れ**
1. **練習試合**: 少しランダムに手を選んで16ゲーム遊び、プレイの記録を集める(1ゲーム200手で打ち切り)
2. **学習**: 記録から予想より良かった手を選び、その手を選ぶように Kev の重みを調整する(`kev.train`、LoRA)
3. **実力テスト**: ランダムなしで5ゲーム遊ぶ(同じブロック順、500手で打ち切り)。平均得点をその世代の成績にする

**運用**
- 配信画面は http://127.0.0.1:8765/ 、学習の操作ページは `/control`(開始・一時停止・再開・停止)
- 学習は止めるまで世代を重ね続ける(`--generations 0`)
- 構成の詳細は [README](../README.md) と [Kev ローカルサーバー運用ガイド](kev-local-deployment.md) を参照
- 環境: RTX 5060 Ti(VRAM 16GB)、Windows 11、Kev-4B(bf16)

- 1ラインあたりの得点は、どの世代も 110〜118 点のままだった(1列消しだけなら100、すべて4段消しなら200)。**ほぼ1列消ししかしておらず、高得点を狙うプレイになっていない**
- 世代間の成績は上下に揺れる(第3世代、第7・8世代で後退)
- v2 の第9世代では、テトリスが1ゲームあたり1.6回に増えた(第6世代は0.2)。一方で、500手まで生き残ったゲームは0/5に落ちた。今の腕前は、生存と高得点が両立しなくなる水準には遠く、これは代償ではなく学習の不足だ。**両方を満たすことを目標にする**

## 4. 現在の段階: 報酬 v2(第9世代〜)

生き残る力は保ったまま、4段消しを狙わせるための見直し。ゼロからではなく、**第6世代から枝分かれ**させた(第7・8世代は v1 の系統として残す)。

| 項目 | v1 | v2 |
|---|---|---|
| 4列消し | +8 | **+16** |
| 高さの増加 | −0.05 | **なし**(4段消しの準備では必然的に高く積むため) |
| 割引率 | 0.9 | **0.97**(何手も先で報われる準備の手を評価しやすくする) |
| 打ち切った練習試合の末尾で評価から外す手数 | 20手 | 60手 |
| 指示文 | 低く平らに保つ | 1列を深い井戸として空け、I ミノで4段消しを狙う |
| 候補の説明 | — | 「最も深い井戸」を追加 |
| 学習データ | 直前2世代分も混ぜる | 同じく直前2世代分。ただし **v2 で選んだ手だけ** |
| テストの成績 | 平均得点 | 平均得点に加えて **1ラインあたり得点・テトリス回数** |

テストの上限は、これまでの世代と比べられるように 500 手のままにした。

**判断の基準**: 数世代(目安は3世代)見て、1ラインあたり得点とテトリス回数が伸びているかを確認する。同時に、生き残り(500手まで生存した数)が崩れていないかも見る。伸びていなければ、次の v3 に進む。

## 5. 次の段階: v3(学習方針の見直し)

**v3 の全体像(2026-09-26 決定、第12世代から実施中)**: 第11世代(v2)のテスト後に切り替え、第12世代を第6世代から学習している。v3 で十分に育てたあと、0.8B に蒸留する。

| 項目 | 内容 |
|---|---|
| 長期的な連携 | 直前10手のウィンドウ(1手ずつずらす)で手を評価する(5.1) |
| 途中での回転・移動 | 左右移動・回転・落下でたどり着ける場所をすべて候補にする(5.2) |
| 穴の報酬の細分化 | 塞がった穴 −1.0、オーバーハング −0.5、解消 +0.8(5.3) |
| 天井近くの減点 | 上から4段以内に積んだときだけ減点する(v2 で生き残りが落ちたため) |
| 練習試合を長く | 打ち切りを200手から400手にして、積みすぎて死ぬ場面も学べるようにする |
| 練習試合での穴の回避と探索 | 穴を作らない候補がある限り、そこから選ぶ(まれに例外)。85%の手は Kev の一番の手、15%だけ上位3候補から探索する(全候補からのくじ引きでは、ありえない盤面ばかりになったため) |
| 4段消しの練習問題 | 練習試合の4分の1を、井戸があり何段か準備済みの盤面から始める |
| 親の世代の選び方 | 直近数世代のうち、テストの成績が最も良い世代を親にする |
| 分岐元 | それまでで最もテストの成績が良い世代(現時点では第6世代) |

**0.8B への蒸留の条件(案)**: v3 の世代が「500手まで5ゲーム中4以上生き残る」「1ラインあたり140点以上」「テトリスが毎ゲーム数回」を満たしたら、その世代を先生にして蒸留する。


v2 の効果を見てから、次をまとめて入れる。v2 の検証が濁らないよう、それまでは入れない。

**5.1 学習データの選び方: 10手ウィンドウ**
4段消しには10手以上の連携が要る。1手ずつ選ぶ方式では、準備の手が評価されにくい。
- 各手で終わる「直前10手」をウィンドウとし、1手ずつずらす
- ウィンドウの評価 = ウィンドウ内で得た報酬 +(終わりの盤面の良さ − 始まりの盤面の良さ)。盤面の良さは、穴の少なさ、4段消しの準備ができた行数、井戸の深さで測る
- 各手の評価は、その手を含むウィンドウの評価の平均。4段消しを含むウィンドウには重みを足す
- 同じ手は1回だけ学習データに入れる。ウィンドウ内で新しく穴を開けた手は除く
- ウィンドウの評価は記録の足し引きだけなので、学習時間はほぼ増えない

**5.2 テトリス本体: 滑り込み・回転入れ**
- 今は「上で回転して真下に落とす」置き方だけを候補にしている
- 出現位置から左右移動・回転・1段落としでたどり着ける場所をすべて候補にする。オーバーハングの下への滑り込みも打てるようにする
- 候補は約34通りから40〜60通りに増える見込み(問いかけが長くなり、推論が少し遅くなる)

**5.3 穴の報酬**

| 項目 | v2 | v3 案 |
|---|---|---|
| 完全に塞がった穴が増える | −0.4 | −1.0 |
| オーバーハング(上にブロックがあり、横が開いた空白)が増える | −0.4(穴と同じ扱い) | −0.5 |
| 穴・オーバーハングが解消される(滑り込みで埋めた/上のラインが消えて穴でなくなった) | 0 | +0.8/マス |

解消の加点は、発生の減点より小さくしておく(「わざと穴を作ってから埋める」で点を稼げないようにするため)。候補の説明でも、塞がった穴とオーバーハングを分けて表示する。

**5.4 保留中の案(必要なら検討)**
- 練習試合で、新しく穴ができない候補がある限りその中から選ぶ(すべてで穴ができるときだけ例外を許す)
- 練習試合のくじ引きの温度を 1.0 から 0.5 程度に下げる(Kev サーバーはもともと確率を平たくして返しているため)
- 1世代で学習する手の数に上限を設ける。練習試合が毎回200手まで続くようになると、学習だけで約2時間かかる見積もりのため

### 5.5 v4(第14世代から実施中)

**2026-09-26**: v3 は新ルールで伸び悩んだ(第12世代 36.3 点/ミノ・151手 → 第13世代 30.2・86手)ため、v4 を前倒しした。前半(5.7 の報酬・盤面の評価・名手の記録・テスト10ゲーム)を第14世代から入れ、第12世代を親にしている。後半(下の 1・2)はこのあと入れる。

**第15世代からの調整**: 第14世代(v4 最初)は、テトリスが初めて出た(0.5回/ゲーム)一方、平均84手で負けた。テストの録画では、10ゲームとも「ほとんどの列を18〜20段まで積み、深い井戸を2〜3本残したまま、出現位置で重なって負ける」形だった。そこで次の3点を調整した。
- 一番深い井戸以外の井戸の深さに減点(盤面の良さに −0.3 × 余分な井戸の深さ)
- 積みすぎの減点を12段から始める(v3 は16段から)
- オーバーハングの減点を −0.5 から −0.8 にする。Kev への指示にも「井戸は1本」「盤面の半分くらいまで」を加えた

**第16世代から: 先読み探索を先生にする(v4 後半を前倒し)**: 第15世代も 28.8 点/ミノ・平均83手で改善せず、ルール3になってから5世代続けて頭打ちだった。報酬の調整だけでは足りないと判断した。練習試合の各局面で、現在と次のミノの置き場所の組み合わせを読む2手の先読み探索(盤面の良さは v4 の評価)を先生にする。Kev が打った局面に先生の手をラベルとして付けて学習する(エキスパート・イテレーション / DAgger)。先生だけでプレイさせると、300手を生き残り、1ミノあたり55〜57点を取れる。学習データは、先生と Kev の手が食い違った局面を中心に、1世代あたり最大600手にする。

#### 当初の案

**基本方針**: 長期の戦略を立てられるようにする。見せるのは現在と次のミノだけ、という条件は変えない。

1. **Kev 自身に盤面の良さを答えさせる**: 段階評価の質問を追加して学習させ、手の評価の基準(今は盤面の特徴の単純な式)を置き換える
2. **練習試合で2手の先読み探索**: 見えている現在と次のミノだけで2手の組み合わせを比べ、探索で見つけた手を覚えさせる(AlphaZero 型)
3. **名手の記録を繰り返し学ぶ**: 1ミノあたり得点が高かったゲームを世代をまたいで保存し、学習データに混ぜる
4. **連続テトリスへの加点**: 報酬だけに入れ、ゲームの得点ルールは変えない
5. **テストの精度を上げる**: 10ゲームにして、同じブロック順で前の世代と比べる
6. **ホールド機能(要相談)**: 戦略の幅は広がるが、ルールが変わり過去の世代と比べにくくなる

### 5.7 過去の事例の調査と v4 の報酬(2026-09-26)

| 事例 | 効いたもの |
|---|---|
| Dellacherie の評価関数 | 穴の数、置いた高さ、行遷移、列遷移、井戸の深さの合計、浸食セル(消したラインで埋めた自分のマス)の6つの特徴量 |
| BCTS(Thiery & Scherrer) | 上の6つに「穴の深さ」「穴のある行数」を追加し、CE 法で重みを学習 |
| CBMPI(Gabillon, Ghavamzadeh, Scherrer, NeurIPS 2013) | 数手先まで試しに打つ(ロールアウト)方策改善。少ないサンプルで CE 法と同等。学習に使う盤面は、いろいろな高さから集めた方が良い |
| DQN の実装例 | 報酬 = 1 + 10 × (消したライン数)²。まとめ消しを強く優遇し、ゲームオーバーの罰は小さめ |
| Cold Clear(対戦用 AI) | 安全な間は1列・2列消しを減点、4列消しと T-スピンを加点。連続テトリス、井戸の深さ、覆われたマス、高さの帯も評価 |
| 報酬の整形(Ng ほか 1999) | 盤面の良さの差分だけを足すポテンシャル型なら、最適な方策を変えずに学習を速められる |

**v4 の報酬と評価(案)**

- 状況で変わる消し方の評価: 安全な高さ(最高10段以下)では 1列 +0.2・2列 +0.8、危険な高さでは生き残り優先で v3 と同じ。4列消しは常に +16
- 連続テトリス(Back-to-Back)に +8、T-スピン(T ミノを回転で入れ、四隅のうち3つが埋まっている形)に加点。ゲームの得点ルールは変えない
- 盤面の良さを Dellacherie/BCTS の特徴量(行遷移、列遷移、穴の深さ、穴のある行数、井戸の合計)で測り、ポテンシャル型の整形と手の評価の基準に使う
- 練習問題を、中くらいから高い積み上がりや、穴のある盤面にも広げる(CBMPI の知見)
- 5.5 の案(Kev 自身に盤面の良さを答えさせる、2手の先読み探索、名手の記録、テスト10ゲーム)と組み合わせる

参考: [The Game of Tetris in Machine Learning(Algorta & Şimşek)](https://arxiv.org/abs/1905.01652)、[CBMPI(NeurIPS 2013)](https://papers.nips.cc/paper/5190-approximate-dynamic-programming-finally-performs-well-in-the-game-of-tetris.pdf)、[nuno-faria/tetris-ai](https://github.com/nuno-faria/tetris-ai)、[Cold Clear](https://github.com/MinusKelvin/cold-clear)

**基本方針(2026-09-26)**: テトリス狙いは強く持つが、穴やオーバーハングができたらすぐに直す。第17世代から、穴とオーバーハングが残っている間は1マスにつき毎手 −0.15 のコストを課し(早く直すほど得)、Kev への指示にも「できたらすぐ直し、そのあと4段消しの準備に戻る」を加えた。

### 学習の3段階(2026-09-26 整理)

1. **強化学習(第1〜15世代)**: Kev 自身が試した手を、報酬で「期待より良かった」ものに絞って学習した
2. **模倣学習で初期学習を加速(第16世代〜、4B)**: 人間が設計した評価式の2手先読み(先生)の手を、Kev が出会った局面で覚えさせる(DAgger)。重みの更新は教師あり学習で、上限は先生の強さ(55〜57点/ミノ)。AlphaGo が最初に人間の棋譜をまねたのと同じ位置づけ
3. **0.8B で強化学習に戻す**: 4B から蒸留した 0.8B で、先生のまねをやめる。Kev に盤面の良さも答えさせ、その判断を先読み探索の評価に使う自己改善(AlphaZero 型)。正解は Kev 自身の探索と、実際の報酬で決まる。v5(局面に応じた戦い方、3手の先読み)もここで入れる

### 5.8a 0.8B への切り替え(2026-09-26 決定)

第16世代(先生つき学習の最初)で 47.4 点/ミノ・平均365手・テトリス2回/ゲームまで伸びた。このやり方で頭打ちになったら(1ミノあたり得点と平均手数が2〜3世代続けて伸びない)、Kev-0.8B に切り替える。
1. 4B の最良世代に多めのゲームを打たせ、出会った全局面に先生の手をラベル付けする(これまでの先生つき世代のデータも加える)
2. 元の Kev-0.8B から、このデータで0.8B の最初の世代を作る(蒸留)
3. 0.8B で先生つき学習を続ける(CUDA グラフも有効化)。4B の最良世代に届かなければ 4B に戻す
4. v5(下記)は 0.8B に移ってから入れる

**結果**: 第23世代(4B 第20世代からの蒸留)で 50.4 点/ミノ・平均465.5手。0.8B でも通用するので、第24世代(0.8B の模倣)のあと強化学習に戻す。

### 5.8b 0.8B の強化学習(第25世代〜、2026-09-27 実装)

- **価値の質問**: Kev に「この盤面は残りのゲームにとってどれくらい良いか」を5段階(とても悪い〜とても良い)で答えさせる。次のミノは「不明」として見せる(次の次は見せないルールのまま)
- **Kev 自身の先読み**: 練習試合では、Kev の確率上位4手を仮に置き、置いた後の盤面それぞれに価値の質問をする。「その手の報酬 + 0.97 × 置いた後の価値」が最大の手が探索の答え。15%は上位4手からランダムに試す
- **学習データ**: ①探索の答えを手のラベルにする(Kev の第一候補と違った局面を優先、上限600) ②実際に得た割引報酬(γ=0.97)を5分位で5段階にした価値ラベル(上限600)。段階ごとの平均報酬を世代に記録し、次の世代の探索がそれを使う
- **最初の世代(第25世代)**: まだ Kev の価値の答えが学習されていないので、手のラベルは従来の先生(2手先読み)、価値ラベルだけ新しく学習する。第26世代から Kev 自身の探索に切り替わる
- 実力テストはこれまで通り探索なしの Kev 単体(比較を続けるため)

**第26世代の失敗と修正(2026-09-27)**: 価値の学習1世代だけで Kev 自身の探索に切り替えたところ、練習試合が平均約42手で崩壊した(価値の答えがまだ雑で、しかも値の幅が報酬より桁違いに大きく、手選びを支配した)。次のように直して第26世代をやり直す。
- 価値ラベルを3世代ぶん(先生の手で打ちながら)学習してから Kev の探索に切り替える。価値ラベルの上限は1世代1200件
- Kev の探索は「Kev の手の確率(対数)+ 価値 ÷ 1段階ぶんの幅」で選ぶ。雑な価値だけで自信のある手を覆さない(AlphaZero の PUCT と同じ考え方)
- Kev の探索で練習試合の平均手数が150手を下回ったら、その世代は先生の探索で打ち直す

**第28・29世代(2026-09-27)**: 第28世代も Kev の探索で崩壊(平均71手)。探索自体は正常で(ランダム手なしなら200手の上限まで生存)、原因は15%のランダム手を上位4手から均等に選んでいたこと。上位3手から Kev の確率に応じて選ぶ方式に戻した。第29世代は練習試合が崩壊せず回ったが、Kev の探索が第一候補を変えた手は129だけで、手のラベル279件に対して価値ラベル1200件の偏った学習になり、実力テストは平均207手に落ちた。手のラベルは一致した手も含めて600件まで埋め、価値ラベルは手のラベル以下(最大600件)に揃えた。

**第30世代と方針の立て直し(2026-09-27)**: 釣り合いを直した第30世代も実力テストは平均228手。Kev の探索で手のラベルを作った世代だけが崩れ、先生の探索でラベルを作り価値だけ学ぶ世代(第26〜28世代)は500手前後を保てていた。価値の答え(実際の報酬との相関0.43)が弱く、第一候補を覆した手が危険な手を教えていると判断した。
- 価値ラベルの目標を「ゲーム終了までの割引報酬」から「10手先までの報酬 + 10手後の盤面の手作り評価」に変更(遠い将来のテトリスの有無という運に左右されない)
- Kev の探索は一旦止め、手のラベルは先生、価値だけ鍛える。価値の精度(先生の手を選べる割合・相関)を測り、十分になったら探索に戻す
- 親は直近5世代の最良(第26世代)から。前の世代のデータの混ぜ込みは一旦なし

**第31〜36世代とロールアウトへの切り替え(2026-09-27)**: 立て直し後は 52.5 / 52.4 / **55.7**(第33世代、0.8B 最高)/ 50.7 / 50.0 点/ミノで、ほぼ全ゲーム500手。価値の答えは実際の結果との相関 0.43 → 0.62 → 0.77 まで上がったが、同じ局面の候補手どうしの比較(上位4手から先生の手を選ぶ割合)は 54% → 44% と改善しない。学習データが実際に進んだ局面だけで、選ばなかった手との比較を学んでいないため。
そこで第37世代からは価値の学習をやめ、**Kev 自身のロールアウト**で手のラベルを作る(方策改善、Bertsekas のロールアウト法)。
- 練習試合の局面の6%で、Kev の上位3手をそれぞれ置き、その後 Kev 自身が10手先まで打つ(各2回)。途中の報酬 + 10手後の盤面の手作り評価が最大の手をラベルにする
- 見えないミノは見えないまま: ロールアウトごとに7種袋の残りを並べ替え、その先も別の乱数で引く(実際の未来のミノは使わない)
- 残りの局面は先生の手。ロールアウトのラベルは優先して学習データに入れる
- ロールアウトは「Kev 自身の打ち方」を土台にするので、先生の評価式の上限(55〜57点/ミノ)を超える信号になりうる

### 5.8c v5 報酬とテストの延長(第37世代〜、2026-09-27)

第37世代から、次の3点をまとめて入れて再スタートした。

1. **報酬 v5**: きれいな盤面(穴・オーバーハング・2本目の井戸のいずれもなし)で10段以下なら、1〜3列消しに代償を付ける(1列 −1.0、2列 −1.0、3列 −0.5)一方でテトリスは +16 のままにし、テトリスだけを組み立てさせる。穴があるとき・2本目の井戸があるときは、代償なしの通常のライン報酬(1/3/5/16)で掘り出すことを優先する。穴の据え置きコストを1マス・1手 −0.35 → −0.6、新しい穴 −1.0 → −1.5、新しいオーバーハング −0.8 → −1.2 に強め、解消は +1.0 に上げた。2本目の井戸・幅2〜3列のくぼみは、残る手ごとに −0.1、埋めた分だけ +0.3(整形の重みも 0.15 → 0.3)。他は v4 のまま。試しに先生自身に打たせたところ、1ミノあたり 54〜55 → 58〜63点、テトリスは400手あたり2〜6回 → 9〜16回に伸びた(3ゲーム、いずれも400手まで生存)。
2. **Kev 自身のロールアウトによる手のラベル(継続)**: 練習試合の局面の6%で、Kev の上位3手それぞれを置いたあと Kev 自身にさらに10手打たせる(各2回)。途中の報酬と10手後の盤面の手作り評価でラベルを決める。見えないミノは見えないままにする(7種袋の残りを並べ替えたうえで、その先は別の乱数で引く)。残りの局面は先生の手のまま。ロールアウトのラベルを優先して学習データに使う。先生の評価式を超える、Kev 自身の打ち方に基づく方策改善の信号を狙う。
3. **実力テストを500手から1000手に延長**(10ゲーム、同じブロック順)。1ミノあたりの値は上限を変えても比べられるが、平均手数・「生存」列やグラフは、第37世代より前は500手上限での値であることに注意する。

### 5.8 v5 の案(先生つき学習が頭打ちになったら)

頭打ちの目安: 1ミノあたり得点と平均手数が、2〜3世代続けて伸びない。

1. **局面に応じた戦い方の切り替え**
   - 先生の評価を高さの帯で変える(Cold Clear 型): 低い(3分の1以下)は井戸掘りと4段消しの準備を重視し、1列・2列消しはほぼ評価しない。穴があるときは、穴の上の段を消して解消することを最優先。半分を超えたら生き残り重視で、どの消し方も評価し、高さを強く減点し、平らにする
   - Kev への問いかけに、局面の一行(「低い: 4段消しの準備」「穴あり: 穴の解消を優先」「高い: 生き残り優先」)を加える
2. **複数手の連携**
   - 先読みを3手目まで広げる。3手目のミノは見えないので、7種類それぞれの最善手の平均で評価する(見えない情報は使わない)
   - 先生が選んだ一連の手を、つながりとして学習させる

### 5.6 ゲームのルールの見直し(第12世代から)

- ミノは最上段の中央に出現し、そこで重なったらゲームオーバー(以前は、置き場所が1つでもあれば続行し、どの列にも上から降りてこられた)
- 回転は標準の SRS(回転の中心と壁蹴りの表)。着地後の回転や T-スピンも正しく扱う
- 置き場所は、出現位置から左右移動・回転・1段落下でたどり着ける場所すべて
- 過去の世代の録画は、記録したときのルール(ルール1)で再生する

### 5.9 Kev が自分で結果を読む(第44世代〜、2026-09-27)
これまで候補手の説明には、置いた後の盤面を私たちが計算した結果(消えるライン数、穴、オーバーハング、高さ、凸凹、井戸、テトリス準備済みの行数)を付けていた。Kev はその要約を読み比べるだけで良い手を選べてしまい、「置いた結果を自分で推測する」力が育たない。段階的に外していく。
| 段階 | 候補手の説明 |
|---|---|
| 0(〜第43世代) | 全部入り |
| 1(飛ばした) | 置くマスの座標(盤面の図と同じ列:行)+ 消えるライン数・穴・オーバーハング |
| 2(飛ばした) | 置くマスの座標 + 消えるライン数。盤面の説明の「穴の数」も外す |
| 3(第44世代〜) | 置くマスの座標だけ。指示文で「候補ごとに置いた後の盤面を思い浮かべ、消える行・穴・高さ・井戸を自分で評価して選ぶ」よう指示する |
盤面の図は渡すが、良し悪しの評価(穴・オーバーハング・凸凹など)は Kev 自身がすることにした(消えるライン数も含め、置いた後の盤面の評価結果は一切渡さない。評価のやり方を指示文で伝えるのはよい。段階1・2は飛ばし、第44世代から段階3)。外すたびに成績は一度落ちる。1ミノあたり得点が外す前の最良の95%に戻ったら次の段階へ。親は同じ段階の世代から選ぶ(段階の最初の世代だけ、それまでの最良から)。正解ラベル(先生・ロールアウト)は内部で結果を計算して作るので変わらない。

### 5.10 指示で打ち方を変える(合格後、2026-09-27 構想)
合格の定義: Kev に渡すのは **盤面の図(今と次のミノ)・戦略の指示文・候補手の置くマスの座標だけ**。置いた後の結果や評価(消えるライン数・穴・高さなど)は渡さない。その条件で、全部入りで打ったときの最高成績の9割以上を出し、500手テストの生存も保つこと。

合格したら、指示文で打ち方を切り替えられるようにする。打ち方ごとに報酬を用意し、先生の探索とロールアウトがその報酬で正解ラベルを作る。学習データの2割ほどを別の打ち方にして混ぜ、テストでは打ち方ごとの物差しで「指示に従えたか」を測る。

| 指示 | 報酬に足すもの | 従えたかの物差し |
|---|---|---|
| テトリス狙い(今) | v5 | 1ラインあたり得点、テトリス回数 |
| とにかく低く(テトリスは狙わない) | すぐ消す、高さに強い減点、テトリスの加点なし | 平均の高さ4段以下、生存 |
| 半分以上で耐える | 高さ10〜16段を保つと加点、低すぎ・高すぎは減点、天井で大減点 | 平均の高さ10〜16段、生存 |
| 井戸は左端(0列目)でテトリス狙い | 一番深い井戸が0列目なら加点、他の列なら減点 | テトリスのうち0列目で決めた割合 |
| 井戸は中央付近(4〜5列目)でテトリス狙い | 同じく4〜5列目 | 同じく4〜5列目の割合 |
| 井戸は右端(9列目)でテトリス狙い | 同じく9列目 | 同じく9列目の割合 |

配信では、テストの途中で指示文を切り替えて、同じ Kev が打ち方を変える様子を見せる。

**最優先(2026-09-27)**: 予測(置いた後の盤面の結果)を渡さずに、今の最高得点レベル(第46世代 63.3点/ミノ)で打てるようにする。そのために推論精度を上げる。
- 推論の世代(第49世代〜)は推論の問題だけで学ぶ(手の学習データは混ぜない)。苦手な問題の重点出題(親世代に候補5,000問を解かせ、間違えた問題を優先して2,500問)、2周学習、途中段階の問い(ミノの真下の空きマスの数、ミノの一番下の段)を追加
- 推論が目標(ライン消し95%・空きマス90%・高さ80%・テトリス準備90%)に届くか、伸びが3世代止まったら、予測なしの割合25%から段階的な切り替えへ。切り替え中も推論の問題を毎世代600問混ぜる。指示文は今のまま(予測なしのときだけ「置いた後の盤面は自分で思い描く」一文を追加)

### 5.11 盤面想像ラウンドの結果(第44〜49世代、2026-09-27)

候補の説明を置くマスの座標だけにする代わりに、「消える行・空きマスを覆うか・高さ・テトリス準備の有無」を Kev 自身に答えさせる練習問題(想像ラウンド)を毎世代出した。正答率は、学習前(第42世代)の 消える行6% / 覆う65% / 高さ61% / 準備77% から、第46世代で 94.3 / 78.7 / 99 / 96.7、第49世代で 93.7 / 82.3 / 99 / 96 まで上がった。後半は苦手な問題の重点出題(親世代に5,000問答えさせ、間違えたものを優先して出題)を2周させた。伸びが3ラウンド止まったところで想像ラウンドを打ち切り、離乳(5.12)に進んだ。

### 5.12 離乳(第50〜58世代、2026-09-27)

想像ラウンドだけでは、実際の判断そのものを予測なしでできるかまでは確かめられない。第50世代から、学習データを予測あり・なし両方の形(ラベルは同じ)で用意し、練習試合のうち予測なしで打たせる割合を 25% → 50% → 75% → 100% と世代を追って上げた。1世代あたり想像ラウンド600問、CPU で作る予測なしの教師ラベル2,500件(うち20%は第55世代からテトリス集中練習問題)を混ぜ、テストにも予測なしの回を追加した。

予測なし単体で打った結果(点/ミノ・平均手数・テトリス回数/ゲーム): 第50世代 10.8/52/0、第51世代 24.4/100/0、第52世代 36.1/198/0.3、第53世代 38.6/279/0、第54世代 44.2/500/0.7、第55世代 55.4/500/8.0、第56世代 53.6/500/5、第57世代 53.7/430/6。想像ラウンドの正答率は第53世代の時点で 消える行96 / 覆う88 / 高さ98.3 / 準備96.3 とさらに伸びており、実際の判断に使うことが想像ラウンドの精度自体も鍛えていた。

### 5.13 第58世代からテストも予測なしに(2026-09-27、進行中)

第58世代から、実力テストそのものを予測なし(100%)で行うようにした。結果は 54.4点/ミノ・全ゲーム500手生存・テトリス3.8回/ゲーム。合格ライン(57.0点/ミノ = 全部入り時の最高だった第46世代 63.3点/ミノの9割)まで2.6点差。不足しているのは主にテトリスの回数で、予測ありのテストでは15〜19回/ゲームだったのに対し、いまは3.8回/ゲームにとどまる。第59世代でさらに詰めている。

**今後**: このままテトリスの回数を増やして合格ラインに届かせる。合格したら、指示文で打ち方を切り替える段階(5.10: テトリス狙い/とにかく低く/高くても耐える/井戸の位置を左端・中央付近・右端に固定)に進み、そのあと約60秒のプロモ動画を作る。

### 5.14 テトリス率を上げる(第78世代〜、2026-09-28)
予測なしで合格したあと、第60〜76世代は58〜61点/ミノで頭打ち(テトリスはラインの2〜3割、1ラインあたり約150点)。正解ラベルを作る先生(v5 報酬の2手探索、単独で62〜66点/ミノ)の水準に近づいたため。ここからはテトリス率を上げる方法を順に試す。
1. **v6: ロールアウトを結果で採点**(第78世代〜): 候補手の比べ方を、手作りの報酬ではなく実際に稼いだゲーム得点(100点=1、テトリス=8)と負け(−30)で行い、打ち切り時点の盤面評価は3割の重みだけ残す。先読みは25手(テトリスの準備から決めるまで)、対象は局面の15%
